# Ability Scores

- **Standard Array**
	- Assign pre-defined stats to specific abilities
		- 15, 14, 13, 12, 10, 8

- **Point Buy**
	- Base score 8, spend 27 points - distribute as you want
		- base score can't go above 15 for any score, but it can be pushed over that limit by bonuses provided by species or sub-species.
	- once a base ability score reaches 13, any subsequent increase cost two points instead of one

- **Roll for Stats**
	- Roll four d6's and get rid of the lowest, then add them together. Do this for all stats, then choose which ability scores to assign to each number.

# Armor Class

- Armor Class (Basic) 10 + Armor + Dexterity Modifier
- Armor Class (Barbarian) 10 + Dexterity Modifier + Constitution Modifier
- Armor Class (Monk) 10 + Dexterity Modifier + Wisdom Modifier

# Initiative
- D20 + Dex Modifier

# Damage
- D20 + Strength or Dexterity

# Attack
- D20 + Str/Dex + Proficiency

# Skill
- Stat Modifier + Proficiency Bonus (if applicable)

# Saving Throw
- Stat Modifier + Proficiency Bonus (if applicable)
